                          本文是「设备端音频与语音处理」系列第 7 篇（共 7 篇）。系列导览：从 pipeline 到 Linux 音频栈。

                          公式、命令、术语和 60 项自测清单，适合放在手边随时查。公式按主题分组，命令按排查顺序组织。

                          # 附录 A：公式速查

                          【电平】
dB(幅度) = 20*log10(A/A_ref)
dB(功率) = 10*log10(P/P_ref)
dBFS: 0 dBFS = 数字满刻度
dBu:  0 dBu = 0.775 Vrms，+4 dBu = 1.228 Vrms
dBV:  0 dBV = 1 Vrms，-10 dBV = 0.316 Vrms
dBSPL: 0 dBSPL = 20 uPa，94 dBSPL = 1 Pa

【量化】
SNR = 6.02*N + 1.76  (dB，满幅正弦)
ENOB = (SINAD - 1.76) / 6.02

【采样与时钟】
fs > 2*f_max
MCLK = 256/384/512 * fs
BCLK = fs * slot_bits * slots
LRCLK = fs
漂移样本数 = fs * ppm * 1e-6 * t

【缓冲与延迟】
单 period 延迟 = period_size / fs
buffer 延迟   = buffer_size / fs
buffer_size   = period_size * periods
端到端 ≈ ADC + period 等待 + buffer + 处理 + lookahead + DAC

【双二阶】
w0 = 2*pi*f0/fs
alpha = sin(w0)/(2Q)
LPF: b0=(1-cos)/2, b1=1-cos, b2=(1-cos)/2, a0=1+alpha, a1=-2cos, a2=1-alpha
HPF: b0=(1+cos)/2, b1=-(1+cos), b2=(1+cos)/2, a0=1+alpha, a1=-2cos, a2=1-alpha
Peak: A=10^(G/40), b0=1+alpha*A, b1=-2cos, b2=1-alpha*A,
      a0=1+alpha/A, a1=-2cos, a2=1-alpha/A
1/Q = 2*sinh( ln(2)/2 * BW * w0/sin(w0) )

【FIR】
y[n] = sum_k h[k]*x[n-k]
线性相位: h[n] = h[N-1-n]，群延迟 = (N-1)/2 采样

【动态】
x_dB = 20*log10(|x|)
y_dB = x_dB                    (x_dB <= T)
y_dB = T + (x_dB - T)/R        (x_dB > T)
alpha = exp(-1/(fs*tau))

【AEC / NLMS】
d(n) = s(n) + sum_k h[k]*x(n-k) + v(n)
e(n) = d(n) - w^T(n)*x(n)
w(n+1) = w(n) + mu*e(n)*x(n)/(||x(n)||^2 + delta)
ERLE = 10*log10(E[d^2]/E[e^2])

【波束成形 / DOA】
tau_m = m*d*sin(theta)/c
DAS: y(t) = (1/M)*sum_m x_m(t - tau_m)
MVDR: w = R^-1*d / (d^H*R^-1*d)
GCC-PHAT: R12(tau) = IFFT( X1(f)*conj(X2(f)) / |X1(f)*conj(X2(f))| )

【降噪】
谱减: |S_hat|^2 = max(|Y|^2 - alpha*|N_hat|^2, beta*|Y|^2)
维纳: G = xi/(1+xi)
MMSE-LSA: G = xi/(1+xi)*exp(0.5*∫_v^inf e^-t/t dt), v = xi*gamma/(1+xi)

【重采样】
L/M 有理数比率，44.1k -> 48k = 160/147
截止频率 = min(fs_in, fs_out)/2

【自由场】
声速 c ≈ 343 m/s (20°C)
1 m 距离 ≈ 2.9 ms

                          # 附录 B：命令速查

                          目的命令
                          列声卡cat /proc/asound/cards
                          列 PCM 设备aplay -l、arecord -l
                          列逻辑设备aplay -L
                          当前参数cat /proc/asound/card0/pcm0p/sub0/hw_params
                          当前状态cat /proc/asound/card0/pcm0p/sub0/status
                          播放测试speaker-test -D hw:0,0 -c 2 -t sine -f 1000 -l 1
                          录音测试arecord -D hw:0,0 -f S16_LE -r 48000 -c 2 -d 5 /tmp/t.wav
                          播放文件aplay -D hw:0,0 /tmp/t.wav
                          打印支持参数aplay -D hw:0,0 --dump-hw-params /tmp/t.wav
                          Mixer 列表amixer -c 0 scontrols
                          Mixer 详情amixer -c 0 contents
                          设音量amixer -c 0 sset 'Master' 80%
                          保存/恢复alsactl store、alsactl restore
                          驱动日志dmesg | grep -iE 'asoc|snd|codec|i2s'
                          DAPM 状态cat /sys/kernel/debug/asoc/<card>/dapm
                          时钟树cat /sys/kernel/debug/clk/clk_summary
                          中断cat /proc/interrupts | grep -i i2s
                          I2C 探测i2cdetect -y 0
                          系统调用耗时strace -T -e trace=ioctl,read,write arecord ...
                          往返延迟latmus（alsa-tools）
                          tinyalsatinymix、tinyplay、tinycap、tinypcminfo
                          PulseAudiopactl info、pactl list short sinks
                          PipeWirepw-top、wpctl status、pw-cli info all
                          GStreamergst-launch-1.0 alsasrc ! audioconvert ! alsasink

                          性能与实时性：

                          目的命令
                          CPU 热点perf top -p <pid> / perf record -g -p <pid>
                          调度延迟perf sched latency
                          函数图ftrace: echo function_graph > current_tracer
                          跟踪 sndtrace-cmd record -p function_graph -g 'snd_*'
                          实时抖动cyclictest -t -p80 -n -i1000 -l10000
                          硬件停顿hwlatdetect
                          功耗powertop、turbostat
                          内存分配heaptrack、valgrind --tool=massif
